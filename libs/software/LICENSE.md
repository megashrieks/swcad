# Third-party notices

The icon outlines in `shared/icons.js` are taken from [Lucide](https://lucide.dev)
and redrawn as single paths. No artwork has been changed — each `rect`, `circle`
and `line` was rewritten as equivalent path data so that an icon costs one SVG
element instead of a handful.

Lucide is ISC licensed, and the icons it inherited from
[Feather](https://github.com/feathericons/feather) are MIT licensed. Both licences
permit copying provided the notice travels with the copy, which is what this file is.

Of the icons used here, `database`, `monitor`, `search`, `server` and `smartphone`
come from Feather by way of Lucide and are covered by the MIT notice below. The rest
are Lucide originals under ISC.
